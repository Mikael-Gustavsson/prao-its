# Eleven arbetar i en publik fork som publiceras via GitHub Pages

Eleven forkar det här repot, som är publikt, och varje push publiceras öppet på internet via GitHub Pages i elevens fork. Vi valde det framför ett privat elevrepo eftersom eleven då får se sitt eget spel på en riktig adress direkt, utan att material och spel måste skiljas åt eller kopieras mellan repon. Det ersätter den ursprungliga planen med privata repon och ingen publicering.

## Consequences

- Allt eleven pushar kan alla se, och det går inte att ta tillbaka. Eleven får därför inte lägga fullständigt namn, skola, klass, kontaktuppgifter, intervjuinspelningar, transkriptioner eller intern ITS-information i repot. Se `agents.md` och säkerhetsreglerna på `site/forberedelser.html`.
- Publiceringen ska vara godkänd enligt skolans och universitetets rutiner för minderåriga och externa molntjänster innan veckan.
- Forkar har Actions avstängt från början, och eleven måste välja GitHub Actions som källa under Settings → Pages. Det är steg i måndagens instruktioner.
- Hela materialet (schema, intervjuer, förberedelser) ligger i samma repo som eleven forkar och är därmed också publikt.
