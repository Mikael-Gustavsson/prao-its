PRAO på ITS

Funktioner

Ett namngivet recept som du kan använda om och om igen.

Skapa och anropa

function visaPoang() {
  console.log("Poäng: " + poang);
}

visaPoang();
visaPoang();

Först definieras funktionen: datorn lär sig receptet men kör det inte. Sedan anropas den med visaPoang();. Varje anrop kör receptet.

Indata

En funktion kan ta emot värden i parenteserna. De kallas parametrar:

function laggTillPoang(antal) {
  poang = poang + antal;
}

laggTillPoang(10);
laggTillPoang(50);

Svar

En funktion kan lämna tillbaka ett värde med return:

function arSlut() {
  return liv === 0;
}

if (arSlut()) {
  console.log("Game over");
}

Varför?

  • Du skriver koden en gång och använder den många gånger.
  • Stora problem delas upp i små bitar med tydliga namn.
  • Fel är lättare att hitta, eftersom varje bit går att testa för sig.
