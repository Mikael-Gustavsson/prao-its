PRAO på ITS

Villkor

Att låta programmet välja väg: om något är sant, gör något.

if

if (poang >= 100) {
  console.log("Du vann!");
}

Läs det som: om poängen är minst 100, skriv "Du vann!". Koden mellan { och } körs bara om villkoret i parentesen är sant.

else

if (liv > 0) {
  console.log("Fortsätt spela");
} else {
  console.log("Game over");
}

else betyder "annars" och körs när villkoret inte är sant.

Jämförelser

  • a > b – a är större än b.
  • a < b – a är mindre än b.
  • a >= b, a <= b – större eller lika, mindre eller lika.
  • a === b – a är lika med b. Observera tre likhetstecken.
  • a !== b – a är inte lika med b.

Ett enda = betyder något annat: att lägga ett värde i en variabel.
