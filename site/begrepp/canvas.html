Canvas och spelloop

Hur man ritar i webbläsaren och får saker att röra sig.

Canvas

Canvas är en tom rityta i HTML. JavaScript ritar på den med kommandon.

<canvas id="spelplan" width="640" height="360"></canvas>
const canvas = document.getElementById("spelplan");
const penna = canvas.getContext("2d");

penna.fillStyle = "blue";
penna.fillRect(20, 30, 100, 15);

fillRect(x, y, bredd, höjd) ritar en fylld rektangel.

Koordinater

Punkten (0, 0) är övre vänstra hörnet. x ökar åt höger och y ökar nedåt. Det är tvärtom mot matematiken i skolan.

Animation: spelloopen

Film är många stillbilder efter varandra. Ett spel fungerar likadant. Många gånger per sekund gör programmet detta:

  1. Sudda hela ytan.
  2. Uppdatera variablerna (flytta bollen, kolla träffar).
  3. Rita allt på nytt.
let bollX = 50;

function spelloop() {
  penna.clearRect(0, 0, 640, 360);

  bollX = bollX + 2;

  penna.fillStyle = "red";
  penna.fillRect(bollX, 100, 10, 10);

  requestAnimationFrame(spelloop);
}

spelloop();

requestAnimationFrame(spelloop) ber webbläsaren köra funktionen igen inför nästa bild.

Kollision

Att bollen "träffar" något är bara ett villkor: är bollens x och y inom rektangelns område?

Tips

Låt tangenthändelserna bara ändra variabler. Låt spelloopen göra all ritning.
