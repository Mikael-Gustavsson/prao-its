Git och GitHub

Att spara, dela och kunna gå tillbaka bland sina ändringar.

Git

Git är ett program som håller reda på alla versioner av dina filer. Varje sparad version kallas commit och har ett kort meddelande om vad som ändrats. Går något sönder kan du gå tillbaka till en version som fungerade.

Tänk på ett spel där du sparar innan en svår bana.

GitHub

GitHub är en webbtjänst där projektet sparas på internet. Git finns på din dator, GitHub finns på nätet.

Ord att kunna

  • Repository (repo): projektmappen med hela historiken.
  • Clone: hämta en kopia av ett repo till din dator.
  • Commit: spara en version lokalt, med ett meddelande.
  • Push: skicka dina commits till GitHub.
  • Pull: hämta andras ändringar från GitHub.

Rutinen

  1. Ändra filer och testa lokalt genom att öppna sidan från disk.
  2. Är du nöjd: gör en commit med ett kort meddelande, till exempel Lägg till poängräkning.
  3. Gör push.

Allt detta går att göra med knapparna i fliken Source Control i VS Code.

Bra att veta

  • Commit ofta, efter varje litet fungerande steg.
  • Skriv aldrig lösenord eller personuppgifter i filer som checkas in.
  • Intervjuinspelningar ska inte checkas in.
