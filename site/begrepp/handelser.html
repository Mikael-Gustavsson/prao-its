Händelser och tangentbord

Att låta programmet reagera på det spelaren gör.

Händelse

En händelse är något som inträffar: ett klick, en tangent som trycks ned, att sidan laddats klart. Programmet kan lyssna efter en händelse och köra en funktion när den inträffar.

Klick på knapp

const knapp = document.getElementById("start");

knapp.addEventListener("click", function () {
  console.log("Spelet startar!");
});

Läs det som: när någon klickar på knappen, kör den här funktionen.

Tangenter

document.addEventListener("keydown", function (handelse) {
  if (handelse.key === "ArrowLeft") {
    spelarX = spelarX - 10;
  }
  if (handelse.key === "ArrowRight") {
    spelarX = spelarX + 10;
  }
});
  • keydown – en tangent trycks ned.
  • handelse.key – vilken tangent: "ArrowLeft", "ArrowRight", " " (mellanslag).

Koden ändrar bara variabeln spelarX. Själva ritningen sker i spelloopen.

Prova själv

Skriv ut tangentens namn med console.log(handelse.key) och tryck på olika tangenter. Se felsökning för hur du öppnar konsolen.
