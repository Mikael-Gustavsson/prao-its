CSS

Sidans utseende: färger, storlekar och placering.

Regel

CSS består av regler. En regel säger vilket element den gäller och hur det ska se ut:

h1 {
  color: darkblue;
  font-size: 32px;
}
  • h1 – väljaren: alla stora rubriker.
  • color – egenskapen: vad som ändras.
  • darkblue – värdet: till vad.

Varje rad slutar med semikolon.

Välja med id

Om HTML har <button id="start"> väljer du den med ett hashtecken:

#start {
  background: green;
  color: white;
}

Vanliga egenskaper

  • color – textfärg.
  • background – bakgrundsfärg.
  • font-size – textstorlek.
  • width, height – bredd och höjd.
  • margin, padding – luft utanför och innanför.
  • border – ram.

Koppla till HTML

<link rel="stylesheet" href="spel.css">

Raden ligger i head och pekar ut CSS-filen. Se sökvägar.

Prova själv

Ändra en färg i spel/spel.css, spara och ladda om sidan.
