JavaScript

Sidans beteende: det som händer när någon använder sidan.

Ett program är instruktioner

JavaScript är ett programmeringsspråk. Ett program är en lista instruktioner som datorn gör uppifrån och ned, en i taget.

console.log("Hej!");
console.log("Spelet startar");

Datorn skriver först "Hej!" och sedan "Spelet startar". Texten hamnar i webbläsarens konsol, se felsökning.

Ändra sidan

JavaScript kan hitta ett element via dess id och ändra det:

const rubrik = document.getElementById("rubrik");
rubrik.textContent = "Du vann!";

Första raden hittar elementet med id="rubrik". Andra raden byter dess text.

Regler att minnas

  • Varje instruktion slutar normalt med ;.
  • Text skrivs inom citattecken: "så här".
  • Stora och små bokstäver spelar roll: Rubrik är inte rubrik.
  • Rader som börjar med // är kommentarer. Datorn hoppar över dem.

Koppla till HTML

<script src="spel.js"></script>

Raden ligger nära slutet av body, så att sidans element finns när skriptet körs.
