Loopar

Att upprepa samma sak flera gånger utan att skriva den flera gånger.

for-loop

for (let i = 0; i < 5; i++) {
  console.log("Block nummer " + i);
}

Koden mellan { och } körs fem gånger, med i som 0, 1, 2, 3 och 4.

  • let i = 0 – börja på 0.
  • i < 5 – fortsätt så länge detta är sant.
  • i++ – öka i med 1 efter varje varv.

Datorer börjar ofta räkna på 0, inte 1.

Lista

En lista innehåller flera värden i ordning:

const block = ["rött", "grönt", "blått"];
for (const farg of block) {
  console.log(farg);
}

Loopen tar ett värde i taget ur listan.

Se upp

Om villkoret aldrig blir falskt fortsätter loopen för alltid och webbläsaren hänger sig. Stäng fliken och kontrollera villkoret och räknaren.

I spelet

Loopar används för att skapa många block, en rad i taget, och för att gå igenom alla block och kontrollera om bollen träffat något.
