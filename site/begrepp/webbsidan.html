Hur en webbsida fungerar

Vad webbläsaren gör med dina filer.

Kort version

En webbsida är bara textfiler. Webbläsaren (Chrome, Edge, Firefox) läser filerna och ritar upp sidan på skärmen.

  • HTML säger vad som finns på sidan.
  • CSS säger hur det ser ut.
  • JavaScript säger vad som händer när man använder sidan.

Vill du jämföra med ett hus: HTML är väggar och rum, CSS är färg och möbler, JavaScript är elen som får lamporna att tändas.

Lokalt och publicerat

Under veckan öppnar du sidan direkt från din egen dator. Ingen server eller internetadress behövs. Först när du är nöjd sparar du ändringen på GitHub.

Prova själv

  1. Öppna site/index.html i webbläsaren.
  2. Högerklicka och välj Visa källa. Där ser du filen som webbläsaren läste.
