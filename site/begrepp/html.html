HTML

Sidans innehåll: rubriker, text, knappar och bilder.

Taggar

HTML består av taggar som omsluter innehåll. En tagg har en start och ett slut:

<h1>Mitt spel</h1>
<p>Använd piltangenterna.</p>
<button>Starta</button>

Webbläsaren visar en stor rubrik, en textrad och en knapp. Slut-taggen har ett snedstreck.

Attribut

Attribut ger en tagg extra information. De skrivs i start-taggen:

<button id="start">Starta</button>

id är ett namn. Med det kan JavaScript och CSS hitta just den knappen.

Tagg inuti tagg

<ul>
  <li>Poäng</li>
  <li>Liv</li>
</ul>

Här ligger li inuti ul. Indrag hjälper dig att se vad som ligger i vad.

Ett helt dokument

<!doctype html>
<html lang="sv">
<head>
  <meta charset="utf-8">
  <title>Vårt spel</title>
  <link rel="stylesheet" href="spel.css">
</head>
<body>
  <h1>Vårt spel</h1>
  <script src="spel.js"></script>
</body>
</html>
  • head – information om sidan, syns inte.
  • body – det som syns.

Prova själv

Ändra texten i en h1 i spel/index.html, spara och ladda om sidan i webbläsaren.
